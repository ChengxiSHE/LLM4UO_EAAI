The prospective transport gate is frozen before any provider call. It contains four wholly synthetic, nonbenchmark pairs and two representation arms per pair, for eight logical requests. The largest serialized view is 61,245 bytes, matching the observed maximum size of the fixed 89-pair benchmark population. No benchmark body, benchmark label, proof, solution, evaluator file, request body, response body, or credential is present in the public plan.

Both arms contain the same fact-hash multiset and the same six generic checks. `Flat-K` presents a flat fact inventory; `PCK-K` places each identical fact under exactly one typed proof obligation. The response is a bounded JSON object with one Boolean judgment, a 0--100 confidence value, six categorical obligation results, and at most three supplied fact hashes per obligation. Free-form rationale and unknown fact hashes are rejected.

The controller uses `DeepSeek-V4-Flash` through the pinned AntChat endpoint and the isolated `/Users/chengxi-nju/Desktop/LLM4UO/.venv-preparation` transport interpreter. It permits five concurrent logical requests, at most three ledgered attempts per fingerprint, and at most 1,024 completion tokens. A completed fingerprint and its checkpoint are reused on restart; an unfinished reservation is never silently sent as a new identity. Authentication, model, budget, ledger, and circuit-breaker failures halt globally, while a single request that exhausts retryable transport attempts becomes infrastructure unavailable and does not invalidate completed independent work.
