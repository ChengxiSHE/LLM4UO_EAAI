# NLEquiv-150 routed-skill independent validation

The independent source is SOVER/NLEquiv-150 at commit `df7e53f58f97b551ded1cb816169bb47f84186da` and dataset tree `1be587fb3cbad4fa75ca8f2938f2dd55f8c6f12b`. It contains 150 nonlinear formulation pairs and is licensed CC BY-NC 4.0 for attributed noncommercial academic use. This lineage was not used in the completed FormulationBench experiment.

The custodian produced 150 opaque inference records, 150 answer-free metadata records, and 150 evaluator-only labels. The public projection contains no labels, split names, source pair identifiers, ground-truth mappings, prior LLM mappings, mismatch types, or non-equivalence certificates. Its audit passed before any inference request.

The revised method is a three-arm causal comparison. `Flat-short` presents the canonical leaf facts as one inventory. `Structured-short` routes the identical fact multiset into six equivalence obligations without adding knowledge. `Routed-skill-short` uses the same structured facts and deterministically retrieves applicable cards from a frozen eight-card nonlinear-equivalence library. The cards cover bidirectional feasibility and objective preservation plus domain/range hazards for exponential/logarithmic, power/root, reciprocal, sigmoid/logit, softplus, hyperbolic, and absolute/piecewise transformations. Routing is a label-independent case-folded trigger union with a universal fallback.

All three arms return only `schema` and a Boolean `equivalent`, capped at 64 completion tokens. This directly addresses the FormulationBench failure mode in which the mandatory evidence object caused 33/178 method failures. A three-request worst-envelope capacity plan is frozen at 22,052 request bytes, concurrency five, and three ledgered attempts. Its offline audit passed seven checks with no API call and confirms equal facts across all arms, no labels, deterministic reconstruction, and the frozen short-output contract.

The live capacity gate subsequently passed 3/3 in three physical attempts, with zero retry, zero method failure, zero infrastructure failure, no halt, and zero new sends on restart. The maximum-envelope short-decision contract is therefore eligible for the full 450-request freeze.

If the capacity gate passes, the full independent study will contain 450 requests, one per arm for every pair. The primary comparison will be `Routed-skill-short` versus `Flat-short` full-denominator accuracy with a one-sided exact McNemar test. `Structured-short` is the prespecified mechanism control: it separates representation from added generic knowledge. This source is synthetic nonlinear equivalence data, so even a positive result would support cross-lineage knowledge-routing efficacy on equivalence judgment, not direct solver-code modeling accuracy or universal OR performance.

The full plan is now frozen. It contains exactly 150 opaque pairs and 450 cells, with a largest request of 20,067 bytes. The independent audit passed 11/11 checks: deterministic plan and request reconstruction, all 150 pairs, all 450 cells, three arms per pair, identical pair facts, knowledge cards only in the treatment arm, 64-token output, concurrency five, capacity binding, and no evaluator path.
