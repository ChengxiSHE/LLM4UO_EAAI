# Main figure legends

Status: backend-independent, evidence-bounded draft. Final panel geometry and
display labels remain subject to rendered visual quality assurance.

**Fig. 1 | Benchmark-grounded proof-carrying knowledge compilation.** **a,** A
modeling skill contains a public-input guard, typed evidence extractor,
formulation transformation, semantic verifier, exact resource checker and
provenance record. A library version additionally contains a public-only
router, immutable verifier, frozen benchmark endpoint and lineage ledger; the
untrusted proposer remains outside this boundary. Two canonical skill manifests
and one parent-linked library manifest now reconstruct all 2,985 direct-versus-
mixed identities; their 17,728-bit semantic envelope is a retrospective artifact
measurement rather than a generalization bound. **b,** Development failures
induce typed obligations in a declared finite grammar. Semantic or resource
counterexamples eliminate inconsistent candidates, and an accepted candidate
is stored as a content-addressed proof-carrying artifact. Geometric
version-space contraction is conditional on balanced separating witnesses.
**c,** Exactly one accepting guard activates typed compilation and verification.
Zero or multiple matches, failed verification and failed resource admission
return the stored previous-library output. Accepted-path correctness is
conditional on sound extraction, compilation, backend solution and projection.
**d,** Full-denominator endpoint outcomes partition into correction,
regression, both correct and both wrong. A prespecified grouped promotion gate
either appends an immutable successor or leaves the previous library unchanged.
Prospectively, a prefix code can allocate error budget across candidates and
per-transition regression limits can accumulate only under one fixed target.
Verification certifies declared obligations, whereas benchmark utility remains
empirical. The framework does not prove arbitrary natural-language
interpretation or unrestricted recursive self-improvement.

**Fig. 2 | Endpoint gains and frozen-interface preservation.** **a,**
Full-denominator accuracy of the frozen control and proof-carrying skill or
library for the TSP confirmation cohort (`n = 140`) and OR-Debug confirmation
cohort (`n = 2,845`). Lines connect methods evaluated on the same records;
percentages describe each frozen finite cohort, and the two endpoint definitions
are not pooled. **b,** Paired outcomes partition each cohort into both correct,
correction, regression and both wrong. TSP contains 46 corrections and no
observed regression; OR-Debug contains 1,924 corrections and no observed
regression. **c,** Effect direction across the seven TSP size strata and 100
OR-Debug structural groups. The prespecified one-sided OR-Debug group sign test
uses 65 positive, 35 tied and zero negative groups
(`P = 2.710505431213761 × 10⁻²⁰`). TSP strata share template lineage and receive
no item-level significance claim. **d,** Exact output identity of the
public-only mixed router relative to pinned direct-family execution: 140 of 140
TSP and 2,845 of 2,845 OR-Debug outputs match, with zero route, output, source
or terminal mismatches. Panel d is a retrospective composition audit and does
not recompute accuracy. Zero observed regressions is not a future
non-regression guarantee. Source data are provided as a Source Data file.
